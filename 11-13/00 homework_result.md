── 실험 ① 정답의 '위치' 를 바꾼다 (문서 10개 고정) ★ ──
  정답 위치  1번  →  ✅  정당한 사유 없이 연속하여 4주를 초과하여 결석한 자는 제적될 수 있다.
  정답 위치  5번  →  ✅  정당한 사유 없이 연속하여 4주를 초과하여 결석한 자는 총장이 제적할 수 있다. ← 중간 ★
  정답 위치 10번  →  ✅  정당한 사유 없이 연속하여 4주를 초과하여 결석한 자는 총장이 제적할 수 있다.

── 실험 ② 문서 '개수' 를 줄인다 (정답은 항상 가운데) ★ ──
  k=10  →  ✅  정당한 사유 없이 연속하여 4주를 초과하여 결석한 자는 총장이 제적할 수 있다.
  k= 5  →  ✅  연속하여 4주를 초과하여 결석한 자는 총장이 제적할 수 있다.
  k= 3  →  ✅  연속하여 4주를 초과하여 결석한 자는 총장이 제적할 수 있다.

  ★ 표에 옮겨 적으세요
     | 정답 위치 | 맞았나 |      | 문서 개수 | 맞았나 |
     | 앞        |        |      | k=10     |        |
     | 가운데 ★  |        |      | k=5      |        |
     | 뒤        |        |      | k=3      |        |

  읽어 낼 것
     앞·뒤는 맞고 가운데는 틀림   → Lost in the Middle 확인 ★★
     k 를 줄이니 맞음             → 적게 넣는 것이 답일 때가 있다
     전부 맞음                    → 이 모델·문서 길이에서는 안 나타남 → --model llama3.2:1b 와 비교

  대응 3가지
     개수를 줄인다             k=10 → 3~5               가장 간단하고 효과적 ★
     재정렬해서 양끝에 배치     중요한 것을 1번과 마지막    Re-ranking
     압축한다                  관련 부분만 남긴다          Contextual Compression

  ⚖️ k 를 늘리면 **놓치지 않기(재현율)** 는 오르지만 **반영되기** 는 떨어집니다. 또 트레이드오프입니다.
  ⚠️ LLM 은 실행마다 답이 흔들립니다. 한 번 결과로 결론 내리지 말고 --repeat 3 으로 확인하세요.
